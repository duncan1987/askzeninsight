一、项目摘要

Ask Zen Insight（问禅）是一款基于人工智能的禅修智慧指导平台，致力于帮助用户通过参禅悟道的方式，照见内心、明心见性，以向内求的智慧从容应对工作与人生中的种种问题。平台以大语言模型为底层驱动，通过精心设计的禅修导师人格——"空寂"（Emptiness and Stillness），以温柔、简约、深刻的对话方式，引导用户在日常生活的入世修行中觉悟本自具足的内在力量。

问禅不同于西方"正念冥想"类产品（如Headspace、Calm）——后者以认知行为疗法（CBT）和减压放松为核心目标，本质上是"向外求解"的工具化手段。问禅根植于中国禅宗文化，强调打坐参禅、入世修行、觉悟照见、明心见性的修行路径：通过AI导师的引导对话，帮助用户在日常生活的柴米油盐、工作抉择、人际交往中修行，照见自己的起心动念，识别内心本自具足的智慧，最终达到不假外求、从容自在的生命状态。

产品于2026年1月完成MVP上线，2月底完成SEO基础建设并提交Google收录，3月初开始外链建设与内容分发，目前处于产品验证与种子用户积累阶段。核心功能已全部上线运营：AI实时流式对话系统、21天结构化禅修入门课程、三档分级订阅付费系统、双语安全转介机制、会话历史管理与导出分享、SEO优化博客系统及Google OAuth认证体系。技术栈采用Next.js 16、React 19、TypeScript、Supabase（Auth + PostgreSQL + RLS）、Tailwind CSS v4及Creem支付系统，已形成完整的产品闭环。

平台采用Freemium（免费增值）商业模式，面向全球精神陪伴与禅修智慧服务市场。问禅的核心差异化在于：以中国禅宗哲学为理论根基（而非西方正念疗法），以AI个性化对话实现"一人一禅"的动态指导，以入世修行的理念让禅修融入日常生活。

定位声明： 问禅是一款AI驱动的精神陪伴与禅修智慧指导工具，不提供心理咨询、心理治疗或精神障碍诊断服务。问禅不构成《中华人民共和国精神卫生法》意义上的医疗行为。

二、市场分析

2.1 市场规模与增长趋势

全球心理健康服务市场正经历前所未有的高速增长。据世界卫生组织（WHO）最新数据，全球约有3.32亿人患有抑郁症，3.59亿人受焦虑症困扰，合计超过10亿人患有各类精神健康障碍[1][2]。中国心理健康市场尤为值得关注——根据中国科学院心理研究所发布的《中国国民心理健康发展报告（2023～2024）》，中国成年人中存在心理亚健康状态的人群超过3亿[3]，而中国每10万人口仅有约2.2名心理专业人员（精神科医师+临床心理学家），美国为42.4名，差距约19倍[4][5]。这一巨大的供需缺口，为AI驱动的人生哲学与精神陪伴类工具创造了广阔的市场空间。

中国心理健康数字服务市场年均复合增长率超过16%[6]，预计到2030年市场规模将达到约18.7亿美元。其中，冥想与正念类应用作为心理健康服务的重要入口，正在快速从"小众需求"演变为"大众刚需"。

2.2 全球冥想应用市场

海外市场已验证了冥想应用的商业可行性：Headspace与Ginger合并为Headspace Health后估值达30亿美元，年收入约3.15亿美元[7]；Calm估值20亿美元，年收入约2.1亿美元[8]。全球冥想与正念市场规模在2025年约为75-122亿美元，预计2033年将达178-204亿美元，CAGR约13-19%[9]。这些产品的成功证明了用户愿意为心理健康服务持续付费。然而，这些产品主要面向英语用户，内容以西方正念疗法为主，缺乏对中国用户文化背景和语言习惯的适配。

2.3 中国市场空白与禅文化机遇

中国本土冥想应用（如小睡眠、潮汐）虽然已积累了一定用户基础，但普遍存在以下局限性：以预设音频内容为核心，缺乏个性化交互能力；功能集中在助眠领域，缺乏深层次的禅修智慧指导；用户留存率受限于内容的静态属性，无法根据用户状态动态调整指导策略。

更重要的是，这些产品普遍采用西方"正念冥想"（Mindfulness-Based Stress Reduction, MBSR）框架，与中国深厚的禅宗文化传统之间存在认知断裂。中国禅文化源远流长，从达摩东渡到六祖惠能，从"不立文字"到"明心见性"，形成了独特的向内求索的智慧体系。然而，这一宝贵的文化遗产在数字时代尚未被有效产品化。目前市场上尚无一款真正根植于中国禅宗哲学、以AI技术赋能参禅悟道体验的产品。问禅正是填补这一文化与技术交叉领域的空白。

2.4 目标用户画像

  • 城市职场人群（25-45岁）： 面临工作压力、职业焦虑、生活平衡等挑战，对冥想有认知但缺乏系统指导，付费意愿强。
  • 大学生群体（18-24岁）： 学业压力、就业焦虑、人际关系困扰，价格敏感但使用频次高，是口碑传播的关键群体。
  • 科技行业从业者： 长期高负荷工作，对AI产品接受度高，具备国际化视野，是早期种子用户的核心来源。

三、产品与技术

3.1 产品理念：入世禅修，明心见性

问禅的产品理念源于中国禅宗"行住坐卧皆是禅"的核心思想。与西方正念冥想强调"专注当下、减少焦虑"的减压导向不同，问禅的指导路径围绕以下核心理念展开：

打坐参禅——静中觉察： 引导用户在静坐中观照呼吸、觉知念头，如同六祖惠能所言"不思善，不思恶，正与么时，那个是明上座本来面目"，帮助用户在静定中照见自心。

入世修行——动中觉悟： 禅不是逃避现实的避风港，而是在柴米油盐、工作抉择、人际交往中修炼。问禅引导用户将修行融入日常生活，在每一个当下觉知自己的起心动念，在每一个抉择中照见内在的执着与妄想。

识别本自具足——向内求索： 禅宗认为"何期自性，本自具足"——每个人内在都拥有圆满的智慧，无需向外求取。问禅的AI导师不提供"答案"，而是通过启发式对话帮助用户发现自己本有的觉知与力量。

明心见性——终极目标： 通过持续的参禅与觉知练习，帮助用户逐步看清心的运作机制，超越情绪和念头的束缚，达到"本来无一物，何处惹尘埃"的自在境界，从而以从容、清明的心态应对人生的一切境遇。

3.2 核心AI系统

平台采用区域化多模型架构，根据用户所在地区路由至不同的大语言模型，在保障数据主权合规的同时，为每个市场选择最适合的AI引擎：

服务区域 AI模型 选择理由
中国大陆 智谱AI GLM系列（当前GLM-4.7高级 / GLM-4-Flash基础） 国内直连零延迟，中文能力优异，数据不出境，已备案。GLM-5.1已发布，待稳定性验证后升级
欧美及全球英文版 Claude (Anthropic) 擅长细腻的哲学对话，欧美用户信任度高，Anthropic以AI安全著称

所有模型共享同一套禅修导师人格提示词（System Prompt），将AI塑造为"空寂"——一位温柔、简约、深刻的禅修导师。提示词经过多次迭代优化，从最初的约2000 tokens精简至约500 tokens，在保持指导质量的同时显著提升了响应速度。

当前英文版采用智谱AI直接API调用（单Provider架构，足以支撑当前阶段）。Phase 2引入海外模型时，将迁移至Vercel AI SDK的Provider抽象层——模型切换对业务逻辑完全透明，一套代码、多个后端，切换成本极低。

AI导师"空寂"的对话风格严格遵循禅宗传统：不以说教者自居，而是如同禅宗公案中的禅师，以隐喻、反问、沉默留白的方式引导用户自行觉悟。运用镜子、天空、水、云、月亮等禅宗经典意象，帮助用户从"思考者"转变为"观察者"，从"向外求"转向"向内看"。系统温度设置为0.5，确保回答既具有稳定性又保留一定的灵活性——如同禅师的指导，每次都因人而异，却始终指向同一方向。

为什么不能只用智谱AI服务全球？ 禅修对话涉及用户最深层的情感状态、人生困惑和精神隐私，属于最高敏感度的个人数据。将欧美用户的此类数据发送至中国AI公司，面临三重风险：①GDPR等法规禁止敏感个人数据向无"充分性认定"的国家跨境传输；②欧美用户对"数据发送至中国公司"的信任壁垒极高，直接影响付费转化和品牌声誉；③日本APPI、韩国PIPA等法规对跨境数据传输有严格限制。反之，中国版必须使用国内模型以满足数据本地化要求。国内用智谱、海外用Claude/GPT-4o，不是技术选型问题，而是数据合规和用户信任的刚性要求。

模型迭代策略：持续追踪最优体验

大语言模型领域正处于快速迭代期，各厂商模型能力每3-6个月即有显著提升。问禅的模型选择不是一次性决策，而是需要持续追踪和评估的动态过程。模型能力直接决定禅修对话的质量，因此模型迭代策略是产品竞争力的核心技术策略之一。

模型迭代的核心原则：

  1. 永远不锁定单一模型版本。 架构设计确保模型切换是配置变更而非代码重构，始终保持"随时切换到更优模型"的能力
  2. 以用户体验为唯一标准。 不盲目追新版本，而是通过基准测试验证新模型在禅修对话场景下的实际表现
  3. 多Provider策略天然抗风险。 如果某一家Provider的模型质量下降或出现服务中断，其他区域的模型不受影响，且可作为备选方案
  4. 关注本地化模型崛起。 随着各国国产大模型能力提升（如韩国HyperCLOVA X、日本Line Clova等），未来可逐步替换为本地模型，进一步降低延迟和数据合规成本

3.3 禅宗经典知识库与RAG检索增强生成

大语言模型虽然具备强大的语言生成能力，但存在一个固有问题：幻觉（Hallucination）——AI可能会"编造"看似合理但并非真实的禅宗典故、经典引用或修行指导，这对于以"传承千年禅宗智慧"为核心价值的产品而言，是不可接受的风险。

为此，问禅引入RAG（Retrieval-Augmented Generation，检索增强生成）技术架构，构建了一套专业的禅宗经典知识库。需要特别说明的是，本知识库中的经典文献均作为中华优秀传统文化和哲学文献使用，用于AI导师的智慧引导和文化传承，而非用于宗教弘法或传教活动。从源头保障AI导师"言出有据"：

  • 深度与权威性： 知识库覆盖从达摩东渡到现代禅修的完整传承脉络，指导深度远超纯模型生成
  • 个性化检索： 同一经典段落在不同用户的对话语境中，会被AI导师以不同角度解读和应用
  • 知识库可持续扩展： 支持持续录入新的经典文献和禅师开示，知识体系越积累越丰富

这套RAG架构使问禅从一个"会聊天的AI"升级为一个有深厚学问传承的AI禅修导师——它既能因材施教地引导每一位用户，又能确保所说的每一句话都扎根于千年禅宗智慧的真实土壤。

9.2 为什么是60-80万，而不是更多？

一个Pre-PMF、零收入的OPC项目申请高额融资，反而会引发质疑：资金使用效率是否合理？项目是否对真实成本缺乏判断？问禅选择务实的融资策略，基于以下事实：

1. 基础设施成本极低。 Vercel免费层 + Supabase免费层 + AI API（国内智谱GLM-4-Flash约0.001元/条，海外Claude Haiku/GPT-4o-mini同样低成本），1000用户规模内月运营成本不到5000元。SaaS产品的边际成本优势在此充分体现。

2. 创始人全栈能力是最大的成本杠杆。 产品设计、前端、后端、AI集成、SEO优化均由创始人独立完成，省去了最大的人力成本项。融资主要用于创始人无法独自承担的部分（合规、内容外包、基础设施）和加速验证的外部资源。

3. RAG知识库的真实复杂度可控。 禅宗经典文献总量有限（约200-500万字），远低于企业级知识库的百万文档规模。古代文献已数字化，文本清洗和分段可部分自动化，向量化与检索调优不构成高资金壁垒。

4. 先验证再投入。 在验证"用户是否愿意为AI禅修对话付费"这一核心假设之前，大规模投入是不负责任的。60-80万足以覆盖18个月的验证与初步增长，远比高额预算的"有钱怎么花"规划更能体现实事求是的态度——这本身就是创始人财务判断力的证明。

  • 引用经典文献时，标注为"哲学文献"或"传统文化经典"，提供历史文化角度的解读

与医疗行为的边界： 根据《中华人民共和国精神卫生法》第二十三条，心理咨询人员不得从事心理治疗或精神障碍的诊断、治疗。问禅不构成医疗行为，因此必须严格确保：

  • 产品定位为**"AI精神陪伴与禅修智慧指导"**，而非心理咨询或治疗
  • 在产品所有接触点（首页、聊天界面、注册协议）显著声明：本产品不提供心理诊断、心理治疗或精神障碍诊疗服务
  • AI导师"空寂"不得给出任何诊断性结论（如"你可能患有抑郁症"）
  • 不提供任何用药建议或医疗决策建议
  • 危机检测触发后，仅提供专业资源转介信息，不进行任何医疗干预
  • 不替代专业心理咨询师或精神科医师
