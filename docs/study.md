# 产品需求文档（PRD）— 共学打卡系统

## 1. 文档概述

### 1.1 产品简介
本项目是一款基于 H5网页端 的纯文字共学社区系统。系统引入了“打卡解锁全文”的防流失机制：管理员发布的课程，学员在未打卡状态下仅能试读部分内容；学员必须点击打卡（未登录则引导登录）后，系统才会判定打卡成功，并即时解锁展示完整的课程内容。

### 1.2 用户角色与内容定义
- **学员端**：移动端 H5 网页（微信内或手机浏览器打开）。
- **管理员端**：PC 端后台管理系统。
- **核心机制**：内容截断（未打卡仅可见前N字） + 打卡即解锁 + 强制登录拦截。


## 3. 功能需求与原型草图描述 (Prototypes)

### 3.1 学员端 H5 页面原型描述

#### 3.1.1 页面一：【课程详情与互动页】

**布局结构**：  
顶部标题 → 试读正文区 → 遮罩/打卡按钮栏 → （解锁后）完整正文与评论区。

---

##### 页面状态 A —— 【未打卡 / 未登录状态】

- **顶部区域**：课程标题、发布日期。
- **试读正文区**：仅展示管理员发布内容的前一部分文字（如前200字或前3段）。
- **【内容截断遮罩层】（核心视觉）**：
  - 在试读文字下方，有一个从白到透明的渐变遮罩层，制造出内容未完待续的视觉感。
  - 遮罩层中央常驻一个醒目的按钮：【打卡解锁完整内容】。
- **文末评论区**：隐藏，不可见。

**点击按钮交互规则**：
- 若用户未登录：页面直接跳转至【登录/注册页】。
- 若用户已登录：状态当场变更为“解锁成功”，页面无缝刷新，切换为状态 B。

---

##### 页面状态 B —— 【解锁后状态】

- **试读限制解除**：遮罩层消失，文字向下平滑展开，展示百分之百的完整课程内容。
- **【吸底工具栏】**：
  - 页面底部出现吸底横条，下方为评论输入框（提示“发表你的学习心得...”），输入框限定输入1000字，学员可以输入内容并点击发表。
- **文末评论区显示**：完整内容的最下方，展示“全部评论(X条)”列表，学员可以浏览所有评论，每条评论包含：用户头像（圆形）、昵称、发布时间、评论纯文字内容。

---

#### 3.1.3 页面二：【课程列表页】

- **课程列表**：以卡片形式展示，每张卡片包含课程序号、课程标题、发布时间，默认按照课程发布时间倒序排列。
- 每个课程作为一个独立卡片。卡片左侧为课程序号/小封面，右侧为“课程标题（如：第一课：如何拆解核心需求）”、“发布时间”。
- 未打卡的课程在列表页显示“去打卡解锁”，已打卡的显示“已解锁”。

---

#### 3.1.4 页面三：【我的打卡】
- 并入dashboard页面，在现有内容基础上增加我的打卡日历。
- 打卡日历组件：展示当前月份的日历网格（周一至周日排列）。凡是打卡过的日期数字，背景圈显为绿色高亮，并带有“勾（√）”图标；未打卡的日期为普通数字。

---

### 3.2 管理员后台页面原型描述 (PC端修正)

#### 3.2.1 页面一【新建/编辑课程页】富文本编辑器升级

- 在富文本编辑器中，增加一个【插入内容截断线】的功能按钮。
- 管理员可在文字排版时，自主决定在哪里“截断”。
- 截断线以上的文字前台直接可见，截断线以下的文字必须打卡后可见。

---

#### 3.2.2 页面二【评论审核管理页】
- 布局结构： 顶部筛选栏 -> 中间数据表格。
- 原型草图描述：顶部筛选： 包含“所属课程”下拉选择框、“发表时间”日期选择器、一个【搜索】按钮。
- 数据表格列明细：[复选框] | 评论内容(截取前50字) | 所属课程标题 | 学员昵称 | 发表时间 | 操作操作列： 包含一个红色的【删除】文本按钮。点击后二次确认弹窗“确定删除该违规评论吗？”，确认后前端与后台同步抹除。

---

#### 3.2.3 页面三【打卡数据统计】
- 针对每一期发布的课程，统计每一名学员的打卡学习情况，以二维表格的形式列举。
- 统计表格第1列为序号，第2列为学员昵称，第3列开始为该学员的打卡情况（每期课程单独一列，列名为发布的课程主题名称），若该学员打卡了该期课程，则该列显示“√”，且用绿色填充单元格，否则为空，显示为橙色。
- 打卡某个课程的条件是学员有评论内容发布。

## 5. 核心业务规则 (Business Rules)

### 打卡与解锁的强绑定
- 学员的“打卡记录”即为“内容解锁钥匙”。
- 只要数据库中存在 **当前用户 - 该课程** 的打卡记录，该 H5 页面就永久对该用户渲染完整版。

### 评论区权限控制
- 未打卡的学员可以查看别人的评论，但只有登录后才可以发表评论。
